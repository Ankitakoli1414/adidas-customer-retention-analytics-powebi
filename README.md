# adidas-customer-retention-analytics-powebi
Adidas Retail Customer Retention Analytics project involves building a Power BI dashboard to analyze customer churn, loyalty, and retention strategies using Adidas retail data.


Overview
Power BI dashboard analyzing Adidas customer data to combat churn, boost loyalty engagement, and optimize retail/e-commerce strategies across regions.​

Datasets used:
CustomerDemographics.csv: CustomerID, Age, Gender, Region, IncomeLevel, MembershipSince, PreferredChannel (Store/Online).​
CustomerTransactions.csv: TransactionID, CustomerID, StoreID, ProductCategory (Footwear/Apparel/Accessories), TransactionDate, Amount, PromotionApplied (Yes/No).​
StoreLocations.csv: StoreID, StoreType (Flagship/Franchise/Outlet/Online), Region, OpeningYear.​
LoyaltyProgram.csv: CustomerID, LoyaltyTier (Base/Plus/Premium/Elite), PointsEarned, PointsRedeemed.​
ChurnLabelledCustomers.csv: CustomerID, LastPurchaseDate, ChurnFlag (0=Active, 1=Churned), ChurnReason.​

Key Features:
Churn rate KPIs by region, income, channel, and tier; funnel charts for customer journey.​
Repeat purchase segmentation (Low/Mid/High tiers); product category analysis.​
Promotion impact on amounts; loyalty points earned/redeemed visuals.​
Store performance by type; CLV calculations and segments.​
Multi-page dashboard: KPIs, loyalty insights, store/channel views, customer segmentation.​

Project objective:
Develop a robust, interactive Customer Retention Analytics Dashboard in Power BI using
Adidas data that will:

Consolidate customer demographics, purchase history, store/e-commerce performance,
and loyalty data
Enable dynamic segmentation of high-value, repeat, and churned customers
Provide actionable insights to improve customer retention, loyalty engagement, and
regional strategies
